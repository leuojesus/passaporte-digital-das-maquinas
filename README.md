# Passaporte Digital das Máquinas

MVP acadêmico desenvolvido em parceria com a Tecnoação, para organizar a documentação técnica de equipamentos industriais.

## Tecnologias
- Python 3.12
- Django 5.2 LTS
- PostgreSQL 17
- Bootstrap 5.3
- Biblioteca qrcode

## Funcionalidades planejadas
- Login e permissões
- Cadastro de máquinas e números de série
- Documentos técnicos em PDF e imagens
- QR Code por máquina
- Consulta de ficha técnica pelo navegador
- Histórico simplificado de manutenção

## Execução
Consulte o arquivo de projeto fornecido no pacote ZIP desta atividade. O ambiente requer Python, PostgreSQL e variáveis em `.env`. Não publique credenciais, documentos técnicos reais ou arquivos `.env` no repositório.
