# Validação do protótipo

As três telas de referência simulam uma interface web em Safari iPhone e não uma aplicação nativa. O navegador é responsável pelas barras de hora, bateria e endereço. O endereço localhost:8000 é de teste.

## Roteiro com representante externo
1. Identificar a entrada para cadastrar máquina no menu.
2. Localizar modelo, série, cliente, adição de documentos e QR Code no cadastro.
3. Consultar ficha técnica, identificar manuais disponíveis e interpretar alerta de arquivo indisponível.

Meta de sucesso: 3/3 tarefas sem ajuda (limiar solicitado de 80%). Tempo máximo de compreensão do cadastro: 180 s. Satisfação mínima: 4/5. Registrar tempos, erros, solicitações de ajuda, comentários e condições de teste. Imagens estáticas não comprovam desempenho nem segurança funcional.
